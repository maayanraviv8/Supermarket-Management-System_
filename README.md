# SuperLee Management System

This project was developed as part of the course *"Information Systems Analysis and Design"* at Ben-Gurion University.

## How to Run

To launch the application, run one of the following commands from the command line:

java -jar adss2025_v03.jar GUI
or
java -jar adss2025_v03.jar CLI

Choose the desired interface (Graphical or Command-Line).

## Login Instructions

To access the system using different roles within the SuperLee network, use the following ID numbers:

- **HR Manager**: `123456789`
- **Shift Manager**: `000111222`
- **Driver**: `999999990`
- **Cashier**: `999999991`
- **Storekeeper**: `999999992`
- **Supplier Manager**: `12345`
- **Suppliers**:
    - `100` – No deliveries, no contracts, no orders
    - `101` – Has deliveries and contracts, no orders
    - `103` – Has deliveries, contracts, and orders

Enter the appropriate ID on the login screen to access the relevant system functionalities.
